# TaskFlow

Минималистичный таск-трекер для Android в стиле macOS.

## Возможности
- Карточки задач: название, описание, дата
- Статусы: Решено / В работе / Запланировано (тап по плашке переключает)
- Напоминания: за неделю / за 2 часа / за час / за 15 минут
- «Потом»: задача скрывается на 1 час (свайп вправо или кнопка) и возвращается
- Свайп влево — удаление
- Статистика по статусам, тёмная тема
- Виджет рабочего стола

## Сборка APK без установки софта (через GitHub)
1. Создайте репозиторий на github.com (например `TaskFlow`)
2. Загрузите все файлы проекта (можно перетащить папку с файлами на страницу репозитория)
3. Откройте вкладку **Actions** — сборка запустится автоматически
4. Дождитесь зелёной галочки (~5-10 минут первый раз)
5. Откройте запуск → раздел **Artifacts** → скачайте `taskflow-apk`
6. Перекиньте APK на телефон и установите (разрешите установку из неизвестных источников)
